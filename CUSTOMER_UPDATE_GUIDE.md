# Updating TailorDesk

1. Export and verify a current backup outside the phone.
2. Confirm the new APK comes from the owner and has the same application ID and signing certificate as the installed app, with a higher version code.
3. Install it over the existing app. Do not uninstall TailorDesk or clear its storage.
4. Reopen the app and check shop settings, customer measurements, a recent order, payments, and the version in **More → About TailorDesk**.
5. If installation fails, preserve the installed app, APK, and backup and report the exact message, phone model, and Android version.

This preview has no activation or license-renewal step.

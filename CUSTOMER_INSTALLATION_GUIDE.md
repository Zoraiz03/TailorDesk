# Installing TailorDesk on Android

Get the APK directly from the TailorDesk owner and verify its filename, version, checksum, and source. Open it from Downloads or your file manager. If Android asks, allow installs only from that chosen source, return to the installer, and select **Install**. Do not disable device protection to bypass a warning.

Open **TailorDesk Preview** and complete shop setup. There is no activation or license-import step in this preview.

Business records are stored locally on the device. Open **More → Backup & Restore → Create and export backup**, complete the share/save action, and verify the `.tailorbackup` file exists outside the phone. Backups are unencrypted and there is no automatic cloud synchronisation.

Before using real records, review garment measurements with a working tailor. PDF generation is available, but printer compatibility and Android file-picker/share behavior must be tested on the actual phone and printer.

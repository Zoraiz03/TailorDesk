# Installing TailorDesk on your Android phone

TailorDesk helps you keep customers, measurements, orders and payments on your phone. An **APK** is an installation file for **Android phones**. It does not install on an iPhone. Ask the TailorDesk owner to confirm that your Android phone is suitable before buying or installing.

## Get and install the app

1. Get the APK directly from the TailorDesk owner through the delivery method you agreed with them. Downloading the file may need internet access; daily shop work runs offline after installation and activation.
2. Before opening it, check the sender or download address with the owner using your known contact. Confirm the app version. Ask the owner to help compare the file checksum if supplied. Do not install an unexpected file, a forwarded replacement, or a file marked **TEST / NOT FOR DISTRIBUTION**.
3. Open the APK in Downloads or the app you used to receive it. If Android asks, open **Settings → Allow from this source** for that chosen browser or file app, then return and select **Install**. Wording varies by phone. You can turn that source permission off again afterward. [Android installation guidance](https://support.google.com/pixelphone/answer/7391672?hl=en).
4. If Android blocks the file, shows an unfamiliar security warning, or says it cannot install, stop and contact the owner with the exact message. Do not disable phone protection to work around a warning.
5. Open **TailorDesk**, identified by the ivory thread-spool symbol on emerald green.

## Activate your purchased installation

1. On **Activate TailorDesk**, tap **Download activation request**. Choose **Downloads** or another local folder in the phone's save screen, then tap **Save**. This creates `tailordesk-activation-request.json`. If you cancel, tap the button again.
2. Send that file to the TailorDesk owner through your agreed contact method. **Share request** is another option when your phone offers a suitable destination. Copy is optional; the saved file avoids mistakes when copying text.
3. The request identifies this installation. It does not contain your customer records. Keep using the same installation while waiting for the license.
4. Receive your purchased `.tailorlicense` file from the owner. Save it where you can find it on this phone.
5. In TailorDesk, tap **Import license file** and select the license. The app checks it offline. If it is rejected, contact the owner; a license for another phone will not work here.
6. Close and reopen TailorDesk to check activation remains. Complete shop setup if this is your first use. Later, **More → Settings** shows your activation and entitlement; **More → About TailorDesk** shows the installed version.

## Set up your shop

Enter your **shop name**, phone and address. Your shop details appear on customer receipts. Choose inches or centimetres, the garments you offer, and optional default stitching prices. Review the measurement fields with the owner before entering real jobs. Prices are starting values that can be adjusted when booking an order.

## Enter your first customer and order

1. Open **Customers → Add Customer**. Enter the name and phone number, then save.
2. Open that customer and create a measurement profile for the required garment. Check the unit and whether the figures describe the body or the finished garment. Fill all required measurements and save.
3. Open **Orders** and start a **New Order**. Select the customer, tap **Add garment**, choose the saved measurement profile, and check quantity and charges. Add further garments if needed.
4. Set the delivery date and record any advance payment using the correct method. Review the total and balance, then choose **Save order**. Money is shown in PKR.
5. Reopen the order and check the customer, measurements, delivery date and payment. Ask for training before recording real shop work if anything is unclear.

## Keep a backup outside the phone

Open **More → Backup & Restore → Create and export backup**. Choose a destination in the phone's share screen. Copy the `.tailorbackup` file to a computer, removable storage, or another agreed secure place outside the phone. Check the file actually arrived; cancelling the share screen does not create an external copy. If there is no suitable destination, ask the owner to demonstrate the transfer.

Back up regularly and before every update. A backup kept only on the same phone cannot protect against losing that phone. Backups are unencrypted: protect access to them. There is no automatic cloud sync. A business backup does not contain your activation license. Restore replaces records and must not be practised on live shop data; ask for an isolated demonstration.

PDF generation is available. Printing must be tested with your actual printer and connection before it is promised as supported. Keep the agreed support contact supplied with your purchase.
